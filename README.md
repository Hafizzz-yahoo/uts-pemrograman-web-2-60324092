## Deskripsi Singkat Aplikasi
Aplikasi ini merupakan sistem **CRUD (Create, Read, Update, Delete)** berbasis **PHP Native**, **MySQL**, dan **Bootstrap** 
untuk mengelola data kategori pada sistem perpustakaan.

## Fitur yang tersedia pada aplikasi:
- Menampilkan data kategori
- Menambahkan data kategori
- Mengubah data kategori
- Menghapus data kategori
- Koneksi database menggunakan MySQL

## Cara Instalasi dan Menjalankan Aplikasi
1. Clone atau download repository dari GitHub.
2. Pindahkan folder **uts_60324092** ke folder web server:
   - XAMPP → `C:\xampp\htdocs\`
3. Jalankan **Apache** dan **MySQL** melalui XAMPP/Laragon.
4. Buat database **uts_perpustakaan_60324092** di phpMyAdmin, lalu import file **database_backup.sql**.
5. Sesuaikan konfigurasi database pada file **config/database.php**.
6. Buka browser dan akses: http://localhost/uts_60324092
